# Генерация уровней TomeNET

Термины для описания структуры случайно создаваемых этажей данжей.

## Язык предметной области

**Шаблон комнаты**:
Описанный в данных фрагмент этажа с заданной формой, рельефом и позициями монстров и предметов. Может содержать прозрачные клетки, через которые сохраняется исходный этаж.
_Избегать_: вкрапление.

**Vault**:
Существующий в игре особый тип комнаты с собственными правилами построения. Шаблон комнаты — отдельный тип, который не наследует правила vault.
