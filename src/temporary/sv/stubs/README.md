# Временные заглушки SV

Этот каталог содержит подстановки для ещё не подключённых частей клиента.
Они используются production-путём, но отделены от основных модулей SV.
В местах подключения заглушки видны по явному include из `temporary/sv/stubs`
и именам `sv_stub_*` / `SV_STUB_*`.

| Файл | Что временно подставляется | Где используется | Чем заменить |
|---|---|---|---|
| `play-profile.h` | Фиксированные 199 опций, viewport 66×22, профиль без звука/музыки/графики и пользовательских visual mappings | `protocol/login.c`, пакет `PKT_PLAY` | Подготовленный профиль опций, карты и выбранных ресурсов |
| `pregame-ui.h` | Тексты Guide в разработке и завершения startup с ожиданием live session | `endpoint-run.c`, `ui/endpoint-scene.c` | Содержимое Guide и передача управления реализованной игровой сессии |

Значения профиля сохраняют прежние рабочие bytes; отсутствие ресурсов честно
сообщается серверу. Заглушки не имитируют успешную загрузку настроек или вход
в игровую сессию. Версионные условия, размеры протокольных таблиц, сериализация,
отрисовка и переходы взаимодействий остаются в основных модулях.

При переносе поведение не изменено. Диагностическая обвязка находится отдельно,
в `tests/sv/diagnostics/`; заглушки не являются тестовыми fixtures.
