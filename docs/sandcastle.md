# Процесс реализации Sandcastle

2026-10-27: по решению пользователя прежний процесс полностью удалён:
контроллер, контракты, recovery, host approval, команды `sandbox:*`,
зависимость npm и тесты обвязки. Новый процесс предстоит построить с нуля.

Правила дальнейшей реализации закреплены в [AGENTS.md](../AGENTS.md#процесс-реализации):
минимальные правки для цели задачи, только необходимый минимум тестов самого
core через production-путь; расширение проверок — после согласования.

Старые отчёты запусков, ретроспективы и материалы `.scratch/sandcastle-*`
сохраняются как история и не задают требования новому процессу.
Локальные credentials, результаты запусков и worktrees не удалялись;
`.sandcastle/.gitignore` сохраняет их исключение из Git.
