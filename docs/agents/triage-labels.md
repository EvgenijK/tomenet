# Triage labels

Local Markdown stores category and state roles in a `Labels:` line. The five state labels use their standard names:

| Role | Local label |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

The category labels are `bug` and `enhancement`. For example: `Labels: bug, needs-info`. `Labels:` is independent of Wayfinder `Status:` and SV `Статус:`; existing files receive no labels as part of this setup.
