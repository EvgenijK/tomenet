# Текущие платформы сборки и проверки SV

Решение пользователя от 2026-10-28, действует до отдельного решения о возврате
Windows в проверяемый scope.

Для всех задач и этапов SV (A, B, C001–C064, исторических C–G,
архитектурных задач и verification tickets) текущая обязательная платформа
сборки, автоматизированных тестов, runtime, visual/input review и приёмки — Linux.

Windows-сборки, MinGW cross-build, Wine и actual Windows runtime/visual/input/
provider/packaging проверки временно отложены. Их не запускают в рамках текущих
задач; отсутствие или прежний отказ этих проверок не блокирует текущую приёмку.
Задача, посвящённая только Windows-сборке или проверке, остаётся отложенной по
этому решению, а не получает фиктивный PASS. Если задача содержит также Linux
работу, её текущий результат принимается по применимым Linux требованиям.

Все прочие требования задачи сохраняются: production-путь, игровая и протокольная
семантика, Linux providers, доступные renderer/build branches, input/lifecycle,
точные bytes и необходимые проверки. Отсрочка Windows сама по себе не закрывает
задачу с другими незавершёнными требованиями.

Это правило имеет приоритет над прежними требованиями задач, планов и документов
к обязательной Linux/Windows, cross-platform, MinGW/Wine matrix. Canonical
capability IDs, ownership, behavior descriptions и распределение этапов
сохраняются; существующий Windows-код и build targets остаются доступными.
Отсрочка проверки не подтверждает полноту Windows-реализации.

Исторические отчёты, failed/pending observations, команды воспроизведения старых
запусков и сохранённые evidence не переписываются как успешные. При чтении таких
материалов текущий scope определяется этим правилом; старые Windows blockers
не переносятся в новые acceptance decisions. Инструменты старых полных matrix
могут по-прежнему запускать Windows: их команды воспроизведения относятся к
прежнему scope и не являются обязательной командой текущей задачи. Для текущей
задачи выбираются применимые Linux проверки без изменения исторического отчёта.
