## Замена временного UI C006 — решение 2026-11-09

Пользователь поручил явно закрепить замену текущего F6 resource editor продуктовым
интерфейсом. В C044 задача 002 переносит font/resource selection и preview в
согласованную Settings surface, затем удаляет временный UI и его native wiring.
Production core C006 и его семантика сохраняются. Задача 001 связывается с тем же
Settings draft/Save owner; второй независимый редактор не создаётся.

**Критерий завершения C044:** продуктовые операции выбора, preview, Save, Cancel
и dirty-close доступны в согласованном интерфейсе; временный F6-экран, его
glyph atlas/debug controls и отдельный shortcut больше не входят в production
сборку и пользовательский flow. Новый вид и bindings определяются подтверждённым
UX prototype, а не наследуются автоматически от временного редактора.
Это обязательная часть C044, не необязательная уборка после его приёмки.

Добавление 002 не превращает этот индекс в полный план всех 22 outcomes C044,
не переносит fonts IDs из C006 и не меняет canonical allocation/statuses.

Самодостаточная задача содержит production seam, работу, минимальные Linux
проверки и критерии завершения. C004 принят и завершён решением пользователя
2026-11-09; его оставшиеся проверки и исправления выполняются здесь и в связанных
поздних owners, без автоматического переоткрытия C004. Его три IDs, conditions
и девять obligations сохраняются в canonical allocation; evidence своего этапа
можно связать с C004 для трассировки, это не gate уже состоявшейся приёмки.
Windows/MinGW/Wine deferred; новые broad suites и full plans здесь не создаются.
