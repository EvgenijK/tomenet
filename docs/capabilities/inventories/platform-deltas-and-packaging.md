# Platform deltas and packaging: статический аудит

Дата: 2026-09-14. Область: Linux/X11, SDL3 Linux amd64, SDL3 Windows i686 MinGW32. Это inventory исходников и packaging recipes, а не свидетельство успешного запуска сборок или готовых архивов. Никакие сборки, установки, downloads и release operations в этом исследовании не выполнялись. Требования продукта и политика минимального пакета остаются решениями карты.

Классификация evidence: таблицы описывают source-backed семейства platform behavior. Exhaustive preprocessed reachability audit всех receivers/configurations не выполнен; SHOW_SANITY проверен адресно. Конкретные реально shipped `.so`/DLL filenames, codecs/backend динамическая загрузка и полнота installed runtime closure требуют собранного artifact и запуска на целевой OS. Набор доступных локально dev tools/libraries отличается от CI builder и не является доказательством готовности всей baseline toolchain.

## Compile-time consistency и зависимости

`receive_tbl[PKT_SANITY] = Receive_sanity` зарегистрирован без feature guard; прототип также без guard. Сейчас `SHOW_SANITY` включён в `config.h`, поэтому дефект default build здесь не установлен. Но при отключении флага функция существует и возвращает 1, а весь `Packet_scanf` и обновление state отсутствуют. Это **stream-consumption hazard**, а не обязательная compile error: надо проверить, что каждый зарегистрированный receiver потребляет пакет во всех разрешённых feature configurations. [Регистрация](../../../src/client/nclient.c#L403), [прототип](../../../src/client/netclient.h#L105), [флаг](../../../src/config.h#L777), [guard вокруг parsing](../../../src/client/nclient.c#L2084).

Default/current, all optional disabled, each optional enabled, GCU yes/no и SHOW_SANITY off — различимые configurations для будущей проверки; существующий CI не выполняет такой matrix. По Notes завершённый новый клиент не сохраняет terminal fallback; текущий release GCU нельзя автоматически сделать его требованием.

Fedora41 installer задаёт версии SDL3/ttf/image/net/mixer, но skip condition — `--atleast-version`, поэтому это нижняя граница при уже установленных пакетах, не exact lock. Download идёт по upstream GitHub release URL через wget и сразу tar, без проверки digest в этих функциях; остальные packages разрешаются через dnf --refresh. Наличие immutable builder image может фиксировать конкретный CI run, но recipe сам по себе не доказывает битовую воспроизводимость или точный набор codecs. [Versions](../../../.github/docker/fedora41/install-build-requirements.sh#L31), [native skip/download](../../../.github/docker/fedora41/install-build-requirements.sh#L90), [MinGW skip/download](../../../.github/docker/fedora41/install-build-requirements.sh#L135).

## Клавиатура, text input, clipboard

SDL3 `react_keypress` получает scancode, игнорирует modifiers, вычисляет modifiers через `SDL_GetModState`, AltGr трактует как Alt, num-lock намеренно считает выключенным, переводит navigation/modifier combinations в legacy sequences и отправляет `Term_keypress`. [Код](../../../src/client/main-sdl3.c#L1173). Это не полноценный text/IME adapter: event dispatcher выбирает window для `SDL_EVENT_TEXT_INPUT`, но switch обрабатывает только `SDL_EVENT_KEY_DOWN` и window events; TEXT_INPUT/TEXT_EDITING commit/preedit там не применяется, `SDL_StartTextInput` в этом backend отсутствует. Наличие enum TEXT_INPUT не доказывает поддержку IME. [Dispatcher](../../../src/client/main-sdl3.c#L1375). Новый semantic UI должен отдельно решить command bindings, text commits/preedit и encoding, не теряя baseline special-key/macro semantics.

X11 copy/paste требует `xclip`, выводит сообщение при helper failure и использует временный `__clipboard__`; SDL3 использует `SDL_SetClipboardText`/`SDL_GetClipboardText`. Полученный OS text всё ещё проходит shared client restrictions/conversion, поэтому SDL API не доказывает произвольный Unicode end-to-end. [Copy](../../../src/client/c-util.c#L2257), [SDL copy](../../../src/client/c-util.c#L2375), [paste](../../../src/client/c-util.c#L2442), [SDL paste](../../../src/client/c-util.c#L2502). X11 screenshots могут вызывать ImageMagick `import`, SDL3 saves window surface самостоятельно. [X11](../../../src/client/c-files.c#L2741), [SDL3](../../../src/client/main-sdl3.c#L5310).

## Filesystem и external integration

SDL3 executable root берётся через `SDL_GetBasePath`; пользовательский root — `TOMENET_SDL3_USER_PATH` либо `SDL_GetPrefPath(SDL3_ORG_NAME, SDL3_GAME_NAME)`. Сейчас identity — `TomenetGame` / `tomenet`. Путь нормализуется, override directory проверяется/создаётся. [Initialization](../../../src/client/client.c#L1327), [override](../../../src/client/client.c#L1340), [identity](../../../src/config.h#L860). Initialization делает chdir в game path, `TOMENET_PATH` и DEFAULT_PATH управляют lib root; config ищется в пользовательском root с bundled fallback. [lib path](../../../src/client/c-init.c#L141), [config](../../../src/client/client.c#L155). Часть helpers использует relative temporary filenames и guide обновляет installation-root файл, следовательно writable user root не гарантирует успешную запись всех функций. [Guide path и backup](../../../src/client/c-util.c#L17194).

Продуктовую storage policy см. в актуальном **Define settings and migration boundary**: она уточнена пользователем после этого статического аудита. Не выводить требование независимого profile root из прежнего решения; текущие исходники используют единый SDL3 user root. Fonts/audio читают user overrides перед bundled assets; audio configs пишутся в user resources, tiles cache в user graphics/cache. [Решение](../issues/05-define-settings-and-migration-boundary.md), [fonts](../../../src/client/main-sdl3.c#L523), [sound fallback](../../../src/client/snd-sdl3.c#L1449), [audio config writes](../../../src/client/snd-sdl3.c#L4109), [cache directory](../../../src/client/main-sdl3.c#L4128).

SDL3 FILEMAN строит file URL, исправляет relative path через SDL3_GAME_PATH, использует SDL_OpenURL и сообщает failure; browser URL открывается той же API. X11 вызывает xdg-open, legacy Windows ShellExecute. [Integration](../../../src/client/c-cmd.c#L6954). Присутствие SDL API не отменяет OS association/default browser/desktop prerequisites. X11/legacy helper inventory включает xclip, import, xdg-open, 7z, grep/ls, wget/sha256sum; SDL3 без archive/curl **не** переключается на legacy external extraction/download/checksum helpers, а сообщает о ручном действии. Windows screenshot scripts всё ещё копируются packaging recipe, что отдельно от их применения SDL3 screenshot API. [Archive guards](../../../src/client/c-util.c#L15986), [guide guards](../../../src/client/c-util.c#L17275), [Windows packaged helpers](../../../.github/docker/fedora41/release-client-sdl3-win32.sh#L28).

## Сеть и OS gates

SDL3_net adapter скрывает asynchronous sockets за small integer pseudo-fd; DNS/connect ждут с timeout. `localhost` переписывается в `127.0.0.1` из-за IPv6/current server mismatch. `GetPortNum` возвращает 0, graceful shutdown API отсутствует. [Adapter](../../../src/common/net-sdl3.c#L1), [connect](../../../src/common/net-sdl3.c#L122), [local port](../../../src/common/net-sdl3.c#L214), [close](../../../src/common/net-sdl3.c#L500). Shared code специально исключает SDL3 pseudo-fd из Unix syscall branches; socket delay/buffer tuning для SDL3 отсутствует. [Guards](../../../src/client/c-init.c#L3838), [tuning](../../../src/client/nclient.c#L1489).

X11 interface discovery и real MAC отличаются от SDL3 local-address identity и deterministic fake MAC fingerprint (включая user path). Это handshake/state delta, не renderer detail. [Interface](../../../src/client/c-init.c#L3883), [fake MAC](../../../src/client/c-init.c#L4069), [port handshake](../../../src/client/c-init.c#L4127). Изменение profile path может менять fingerprint; продуктовая политика identity требует решения, а не автоматического переноса Linux ioctl к SDL sockets. VERSION_OS distinguishes MINGW от WIN32 и SDL3 OS subcode. [Identity macros](../../../src/common/defines.h#L139).

## CI, runtime closure и release contents

Активный build-release workflow вызывает **fedora41** recipes (параллельные fedora43 файлы не источник этого workflow). Compile check собирает Linux server/X11, legacy MinGW Windows и SDL3 `clean all` с HAVE_WINE=no. Это compile/link coverage, не runtime Windows smoke, IME, display, audio codecs или optional dependency matrix. [Compile check](../../../.github/workflows/build-compile-check.yml#L48), [active release](../../../.github/workflows/build-release-assets.yml#L62). Builder installs native SDL projects и MinGW devel archives, curl/OpenSSL/archive/fonts/codecs, Wine; наличие Wine для tool generation не равно client runtime test. [Provisioning](../../../.github/docker/fedora41/install-build-requirements.sh#L62), [SDL installs](../../../.github/docker/fedora41/install-build-requirements.sh#L171).

Linux recipe копирует binary, tomenet.cfg, COPYING, README.md, guide, APAC/EU/NA launch scripts и **весь lib**, затем recursive ldd dependencies в корень архива. Excludes loader, glibc-family и libtinfo; copied libraries получают `$ORIGIN` RPATH. Следовательно пакет сохраняет system ABI requirements; это не universally standalone binary. ldd parser берёт только строки `=> /`, не проверяет `not found`, не устанавливает динамически загружаемые codecs/plugins/data по отдельному manifest. [Recipe](../../../.github/docker/fedora41/release-client-sdl3-linux.sh#L23), [closure](../../../.github/docker/fedora41/release-common.sh#L39).

Windows recipe переименовывает tomenet.exe в TomeNET.exe, копирует тот же config/docs/lib, региональные .bat плюс screenCapture.bat/Take-ScreenShot.ps1 и recursive imported DLL closure. Resolver ищет target sysroots; OS DLL whitelist не копируется; отсутствующая non-system DLL даёт **warning и continue**, не fail. Import-table recursion не покрывает LoadLibrary/runtime-selected libraries, TLS CA material, OS associations или fonts/audio data вне lib. [Recipe](../../../.github/docker/fedora41/release-client-sdl3-win32.sh#L23), [DLL recursion](../../../.github/docker/fedora41/release-common.sh#L111).

Оба recipe используют `cp -a lib` без exclusions: состав архива равен содержимому checkout/workspace lib на момент запуска, а не отдельному allowlist assets. Для локального грязного workspace это может включать пользовательские файлы; свежий CI checkout — отдельный случай. Новый package manifest и политика источника assets должны быть явными. [Linux copy](../../../.github/docker/fedora41/release-client-sdl3-linux.sh#L28), [Windows copy](../../../.github/docker/fedora41/release-client-sdl3-win32.sh#L29).

Архивы SDL3: `tomenet-V-client-sdl3-linux-amd64.tar.bz2` и `tomenet-V-client-sdl3-win32.zip`; рядом существуют X11 client/server и legacy Windows archives. V читается из defines.h: три компонента при нулевых extra/branch/build, иначе шесть. Release workflow сверяет tag vV с defines.h; upload и attach используют централизованные имена пяти assets. Verify-assets подтверждает присутствие архивов, не проверяет состав и runtime closure. [Version](../../../.github/docker/fedora41/release-common.sh#L23), [asset identities](../../../.github/actions/ci-release-assets/action.yml#L90), [tag guard](../../../.github/workflows/build-release-assets.yml#L34), [verify action](../../../.github/actions/ci-verify-assets/action.yml), [attach](../../../.github/workflows/attach-release-assets.yml#L175). Новый binary/asset/config identity пока не выбран; текущие binary names совпадают с legacy и требуют явного решения для coexistence.

## Что должен решить следующий frontier

- [Name and ship the new client across platforms](../issues/08-name-and-ship-the-new-client.md): binary/asset/config identity, profile root vs existing writable xtra, minimum OS/glibc ABI, portable/install layout, допускаемые внешние helper prerequisites, состав штатного пакета и политика shared resource updates.
- [Design parity evidence and acceptance](../issues/09-design-parity-evidence-and-acceptance.md): обязательные build-feature configurations, disabled receiver stream-consumption check, package extraction/closure failure checks, Linux/Windows runtime smoke, аудиокодеки/PNG-BMP fallback, text/IME/clipboard и network timeout evidence. Runtime-loaded dependency/data closure нельзя объявлять доказанной только ldd/objdump; checksum stub return 0 при отключённой функции не доказательство актуального guide.
- [Define encoding and glyph identity](../issues/22-define-encoding-and-glyph-identity.md) и [Choose raster references and defect compatibility](../issues/23-choose-raster-references-and-defect-compatibility.md): SDL key-down baseline отделить от нового text/preedit маршрута; input protocol/macro compatibility и display encoding доказать независимо.

Это sharp вопросы для существующих decision tickets. Аудит не выбирает ответы и не заявляет runtime parity на основании статического чтения.
