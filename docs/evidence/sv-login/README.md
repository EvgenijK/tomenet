# Артефакты приёмки login UI

Макет хранится в отдельном проекте `Projects/github_site/tomenet_interface/`
(репозиторий `git@github.com:EvgenijK/EvgenijK.github.io.git`, подкаталог
`tomenet_interface/`). Копии HTML/CSS/JS макета в клиенте нет.
Для исторической приёмки B2 использован commit
`1bb2d5d45b9001bf2a6f2084f78184c29a73fca7`, variant D.

Здесь сохранены только материалы о происхождении ресурсов:

- `PROVENANCE.md` — историческое описание копирования и native-адаптаций.
- `SHA256.json` — исторические контрольные суммы эталона и ресурсов.

Манифест и provenance сохранены без изменения байтов. Упоминание локальной
`reference/` в provenance описывает прежнюю структуру, до удаления копии.
Ключи манифеста разрешаются следующим образом:

- `PROVENANCE.md` — относительно этого каталога;
- `reference/*` — без префикса `reference/`, относительно внешнего проекта
  `tomenet_interface/` указанной версии;
- остальные — относительно `lib/xtra/sv/login/` в клиенте.

Перед удалением копии все пять файлов макета побитово сверены с внешним
проектом и историческими контрольными суммами: различий нет.
PNG, редактируемые SVG-исходники, TTF, лицензия и используемый кодом `logo-data.h`
остаются в `lib/xtra/sv/login/`: это ресурсы клиента.

Скрипты `capture-reference.cjs` в `docs/evidence/sv-b2-001/`…`sv-b2-004/`
читают HTML/CSS/JS из внешнего проекта, а фоновые PNG — из ресурсов клиента.
По умолчанию макет ищется в `../github_site/tomenet_interface` относительно
корня репозитория клиента. При другом размещении задайте `TOMENET_INTERFACE_ROOT`:

```bash
TOMENET_INTERFACE_ROOT=/path/to/tomenet_interface \
  node docs/evidence/sv-b2-001/capture-reference.cjs /tmp/sv-b2-reference
```

Для воспроизведения старой приёмки нужен внешний checkout указанного commit;
текущий макет может отличаться. Скрипты не переключают и не изменяют внешний
checkout. Результаты отдельных запусков остаются в соседних
`docs/evidence/sv-b2-*/`. Обновление путей не означает повторной приёмки.
Старые логи и отчёты могут содержать прежнее расположение файлов.
Уже устаревшая до переноса сумма скрипта B2-004 сохранена как историческая;
замечание записано в `docs/sv-improvements.md`.
