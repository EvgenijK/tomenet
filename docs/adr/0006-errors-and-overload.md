# Ошибки изолируются по возможности безопасного продолжения

2026-09-21, Q14. Модули возвращают смысловой результат ошибки, а владелец жизненного цикла решает, требуется ли завершить сессию: отказ дополнительной возможности, например звука, сообщается без разрыва соединения; устаревший выбор обрабатывается по правилам взаимодействия; частичный пакет ожидает продолжения, а предусмотренное протоколом восстановление сохраняется. Если корректность состояния или сохранность обязательных данных обеспечить невозможно, сессия завершается с понятной причиной, при этом приложение остаётся работающим; это предпочтительнее скрытого продолжения с потерянными обновлениями.

При перегрузке сначала ограничивается приём новых данных там, где транспорт это допускает, и обрабатывается накопленное; буферы не растут бесконечно и игровые изменения не удаляются молча. Если продолжение без потери обязательных данных невозможно, применяется явное завершение сессии; конкретные лимиты и механизмы восстановления определяются в соответствующих модулях.
