# Чтение состояния по версиям изменений и производные кэши UI

2026-09-21, уточнённый Q11. Модель остаётся источником истины и предоставляет версии изменений по областям состояния; UI использует их для обновления производного представления, чтобы не обходить, форматировать и компоновать неизменившиеся данные каждый кадр. Маленькие значения возвращаются копией, большие представления доступны только для чтения в фазе построения кадра, когда модель не изменяется; между кадрами UI хранит собственные производные данные и устойчивые идентификаторы, а не заимствованные указатели на объекты модели.

Кэши должны учитывать также изменения шрифта, масштаба, геометрии и других входов представления. Начинаем с версий крупных областей, более подробный учёт изменений вводим по результатам измерений: это экономит повторную подготовку данных ценой явных правил актуализации кэшей; отрисовка и анимации имеют собственную частоту, а разовые реакции не заменяются проверкой версии состояния.
