# Главный поток владеет состоянием сессии и взаимодействий

2026-09-21, раунд Q8. Игровые обновления и пользовательские действия обрабатываются последовательно в главном потоке, который владеет изменяемым состоянием сессии и взаимодействий; ожидание следующего шага ввода не останавливает обслуживание сети и UI. Медленные операции при необходимости выполняются в фоне и возвращают результаты владельцу, не изменяя игровое состояние самостоятельно: это упрощает порядок изменений, отмену и отключение по сравнению с несколькими потоками, совместно меняющими состояние, но требует исключить длительную блокирующую работу из обработчиков.

В Q13 согласован бюджет обработки входов за проход главного цикла: по числу входов или времени, с передачей управления UI между полностью обработанными входами. Остаток переносится на следующий проход, порядок сетевых обновлений сохраняется; непрерывный поток сети не должен вытеснять обслуживание интерфейса. Буферы ограничены, молчаливое отбрасывание игровых изменений недопустимо; конкретные лимиты подбираются измерениями, политика отказа при перегрузке определена в [ADR-0006](0006-errors-and-overload.md).

Контракт межмодульной доставки описан в [ADR-0003](0003-explicit-module-connections.md); конкретный механизм передачи результатов фоновых задач ещё не выбран.
