Геометрия surfaces — throwaway, решения ещё не приняты

Три варианта в игровой основе HTML UX: A — центральная surface, B — раздел справа с отдельной видимой областью карты, C — раздел снизу. Палитра и состав основы взяты из HTML UX; данные синтетические. Это пространственный эскиз, не нормативный UX и не доказательство native parity. Серверный viewport, команды, DPI raster, font mappings и persistence здесь не реализованы. Вписывание карты и специального магазина обновлено по принятым правилам.

Resize меняет настоящий viewport iframe. Resize сам схему не переключает. Малая схема: normal map, правая панель скрыта, над картой пять строк общей ленты; способ включения ещё обсуждается. Размеры панелей и HUD в эскизе ещё не согласованы. A сохраняет центральное размещение HTML UX и показывает риск скрытой позиции игрока. B/C резервируют карту при открытом разделе; сетка вписывается целиком; B/C оставлены только для сравнения.
