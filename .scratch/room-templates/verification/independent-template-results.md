# Независимая проверка вероятности room_templates

Дата: 2026-10-14.

Запуск: `python3 .scratch/room-templates/verification/independent-template-check.py`.

Скрипт извлекает из текущего `generate.c` фактическое условие новой ветки и helpers `room_template_multiplier`, `room_template_total_weight`, `room_template_random`, `room_template_category_roll`, `room_template_pick`, а из `init2.c` — фактическую ветку настройки `DUN_ROOM_TEMPLATE`. Компиляция отдельного C harness с `-Wall -Wextra -Werror -fsanitize=undefined -fno-sanitize-recover=all`; все проверки прошли. Временные исходник и бинарник удаляются автоматически.

## Проверки

- Полный перебор двух глубинных бросков с насыщенной категорией: порог 1, глубины 0/1; порог 7, глубина 3; порог 120, глубины 0/1/30/60/119/120/121. Количество положительных исходов точно равно квадрату глубины, ограниченной порогом: например 900/14400 на глубине 30 и 3600/14400 на глубине 60. На глубине 120 и выше оба броска всегда проходят.
- Значения `DUN_UNUSUAL` 1/120/32767 при одинаковом потоке RNG отдельной проверки дают идентичные результат и конечное состояние RNG. Извлечённое условие содержит ровно два `DUN_ROOM_TEMPLATE` и не содержит `DUN_UNUSUAL`.
- При нулевом scaled-весе новая проверка не расходует RNG. Helpers категории/выбора также не расходуют RNG при нулевом scaled-весе; нулевой baseline отвергается категорией.
- На каждый из девяти сценариев 500000 попыток; исходные веса 100/300. Проверены глубины 30/60/120, множители 0/1/2/11/1000, насыщение категории и доля конкретного шаблона. Допуск абсолютной частоты попыток 0.0015, доли шаблона внутри категории 0.02.
- Фактическая ветка парсера принимает 1/120/32767. Отклоняет 0, -1, 32768, пустую строку, `abc`, `12tail`, `1.5`, переполнение `long`; каждый отказ сохраняет предыдущее значение 77 и выдаёт диагностику.
- Проверка расположения в исходнике: новая ветка после обработки разрушенного этажа и ALWAYS, перед unusual; unusual больше не содержит template helpers. При выбранной категории ветка безусловно расходует попытку через `continue`, включая неудачу размещения.

## Границы проверки

Проверена вероятность попытки и выбор кандидата, а не успешные размещения на игровых этажах. Eligibility заменена двумя подходящими кандидатами; её ограничения, реальные соединения входов, tiny_level, IDDC и ALWAYS не запускались. RNG harness детерминированный, отдельный от игрового RNG. Независимость означает независимость формулы вероятности от `DUN_UNUSUAL`: изменение unusual может менять расход общего игрового RNG и конкретный этаж при одинаковом seed. Полную серверную сборку выполняет основной агент отдельно. Работающий сервер не запускался, не перезапускался и не затрагивался; сокеты не открывались.
