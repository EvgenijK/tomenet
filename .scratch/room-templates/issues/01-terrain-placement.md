# 01: Размещение рельефа шаблона комнаты

**What to build:** Игрок встречает на обычном этаже шаблон комнаты, чьи активные клетки точно воспроизводят рельеф шаблона, а прозрачные сохраняют исходный уровень.

Blocked by: None (can start immediately).

Status: ready-for-agent

- [ ] Сервер загружает шаблон рельефа и три карты с пустыми слоями сущностей; нарушения формата, размера и допустимости рельефа получают диагностическое сообщение с файлом и строкой.
- [ ] На подходящем этаже шаблон размещается целиком в одной из восьми ориентаций; активные клетки получают рельеф и признак комнаты, прозрачные клетки остаются без изменений.
- [ ] Неудачная попытка не оставляет частично нанесённого рельефа и не заполняет прозрачную часть прямоугольника полом.
- [ ] Шаблон комнаты не устанавливает свойства постоянной стены, запрета телепортации или защиты vault; запретные преобразования рельефа правилами этажа отклоняют ориентацию.
