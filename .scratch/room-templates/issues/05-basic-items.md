# 05: Базовая постановка предметов

**What to build:** В отмеченных клетках появляются предметы точного либо случайного базового вида с согласованными фильтрами и качеством.

Blocked by: 01 — Размещение рельефа шаблона комнаты.

Status: ready-for-agent

- [ ] Профиль принимает точный `tval`/`sval` либо случайный выбор через обычный механизм предметов; фильтры вида и качество работают согласно спецификации.
- [ ] Статически невозможные сочетания отклоняют файл; на конкретном этаже действуют ограничения вида, данжа и фактической глубины.
- [ ] Предмет ставится строго в указанную клетку, без переноса; его неудача не отменяет шаблон комнаты и не мешает монстру той же клетки.
- [ ] Один маркер создаёт один игровой объект; стандартный размер стопки сохраняется.
