# 05: Базовая постановка предметов

**What to build:** В отмеченных клетках появляются предметы точного либо случайного базового вида с согласованными фильтрами и качеством.

Blocked by: 01 — Размещение рельефа шаблона комнаты.

Status: ready-for-human

- [x] Профиль принимает точный `tval`/`sval` либо случайный выбор через обычный механизм предметов; фильтры вида и качество работают согласно спецификации.
- [x] Статически невозможные сочетания отклоняют файл; на конкретном этаже действуют ограничения вида, данжа и фактической глубины.
- [x] Предмет ставится строго в указанную клетку, без переноса; его неудача не отменяет шаблон комнаты и не мешает монстру той же клетки.
- [x] Один маркер создаёт один игровой объект; стандартный размер стопки сохраняется.
