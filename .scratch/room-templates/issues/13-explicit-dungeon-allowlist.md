# 13: Только явно разрешённые шаблоны комнат

Status: ready-for-human

Шаблон комнаты может появляться только при наличии `I:+:<код>` в
`d_info.txt` эффективной темы этажа. Отсутствие списка и старый список
`I:-:` не разрешают никакие шаблоны, включая `ROOM_TEMPLATES_ALWAYS`.
Загрузчик сохраняет поддержку старых запретов для совместимости.
