# 04: Монстры шаблона комнаты

**What to build:** Монстры появляются в отмеченных клетках по профилям шаблона, с обычными ограничениями данжа и согласованным поведением уникальных, эго и групп.

Blocked by: 01 — Размещение рельефа шаблона комнаты.

Status: ready-for-human

- [x] Все поля профиля монстра разбираются и проверяются; невозможные статические сочетания отклоняют файл с понятной диагностикой.
- [x] Точный или случайный базовый вид проходит фильтры, тематический пул данжа и предел глубины; каждая отмеченная клетка выбирается независимо.
- [x] При недоступном уникальном выполняется согласованная попытка обычной замены; эго применяется по выбранному режиму без нарушения правил базового монстра.
- [x] Неудача отдельного монстра сохраняет шаблон комнаты; группы и эскорты создаются после всех успешно поставленных основных монстров.
