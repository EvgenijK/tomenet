# 03: Входы и соединение с уровнем

**What to build:** Автор шаблона отмечает проходимые входы, а созданный шаблон комнаты соединяется с остальным уровнем согласно этим меткам.

Blocked by: 01 — Размещение рельефа шаблона комнаты.

Status: ready-for-agent

- [ ] Входы принимаются только на активных проходимых клетках; одинаковые координаты учитываются один раз.
- [ ] Координаты входов преобразуются вместе с рельефом при каждом повороте и отражении.
- [ ] При наличии входов генератор соединяет хотя бы один из них с остальным уровнем; без входов соединение не требуется.
- [ ] Невозможность выполнить обязательное соединение не оставляет частично созданного шаблона комнаты.
