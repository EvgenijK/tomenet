# C012 evidence package

В Git публикуются только компактные итоговые доказательства технической приёмки:

- `final-core-2026-11-13/`: команды, exit codes, source/binary hashes и логи
  существующей Linux сборки и focused production status check.
- `semantic-closure-2026-11-13/report.md`: source-value контракт Study/stat index.
- `final-disposition-2026-11-13/`: сопоставление 27 outcomes / 81 obligations.

Промежуточные browser/native screenshots, временные профили, build snapshots и
диагностические журналы сохранены в локальном рабочем архиве и в этот пакет не
включены. Исторические ссылки на такие пути в документах описывают локальные
артефакты прежних проверок; в чистом checkout они могут быть недоступны.
Отложенная визуальная приёмка требует новых снимков соответствующего consumer.

[итог](../../docs/tasks/c012/final-disposition.md) и
[отсрочки](../../docs/tasks/c012/deferred-acceptance.md).
